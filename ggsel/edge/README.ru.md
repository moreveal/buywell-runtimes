# GGSel через Buywell Edge

Установите пакет и создайте подключение `ggsel.seller`, локально указав seller
ID и API key с доступом Seller API V1. Отдельное GGSel-приложение, service
scripts и Buywell connection key больше не нужны.

События, действия и каталог остаются совместимыми с `ggsel.seller@1.2.3`.

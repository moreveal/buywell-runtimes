# 1.3.9 Edge

- Сбор ответов через сообщения полностью удалён из актуального пакета. «Спросить покупателя» теперь работает только через единую форму.

# 1.3.8 Edge

- Добавлена форма покупателя с безопасным возвратом в заказ или чат FunPay.

# 1.3.7 Edge

- Одно сообщение покупателя теперь может быть использовано только один раз, даже если FunPay прислал его одновременно как новое сообщение и как изменение последнего сообщения чата. Повторная проверка больше не расходует все попытки на одном ответе.

# 1.3.6 Edge

- При повторной попытке ввода отправляется настроенное сообщение о неверном ответе; сервер Buywell канонически проверяет домены, пути и остальные ограничения ответа.

# 1.3.5 Edge

- События заказа теперь передают динамические параметры товара (`period`, способ выдачи и другие поля категории), чтобы настроенные сопоставления входов получали фактическое значение покупки.

# 1.3.4 Edge

- Если покупатель прислал ответ сразу после покупки, до появления вопроса в чате, ожидание ввода теперь использует это свежее сообщение и не отправляет лишний повторный вопрос.

# 1.3.3 Edge

- Ответ покупателя теперь находится и по ID чата, и по участникам переписки, как в проверенном Cardinal runtime.
- Повторная доставка одного ожидания после переподключения не отправляет вопрос второй раз и продолжает ждать тот же ответ.
- Истёкшее ожидание возвращает понятную ошибку вместо пустого сообщения.

# 1.3.2 Edge

- Запускает рабочий цикл FunPay Runner, чтобы опрос заказов и сообщений действительно выполнялся.
- Состояние подключения теперь отражает успешность живого опроса: потеря авторизации требует повторного входа, а зависший опрос помечается как недоступный.

# 1.3.1 Edge

- Интерактивная настройка Edge получает русские и английские названия полей прямо из пакета FunPay.

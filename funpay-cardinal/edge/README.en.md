# FunPay on Buywell Edge

Install the package in Edge and create a `funpay.cardinal` connection. Enter
the `golden_key` and optional User-Agent locally with
`buywell-edge connection add` or `connection login`. The secret is not sent
to Buywell.

Events, actions, catalogs, and versions match the published
`funpay.cardinal@1.3.10`; new connections do not need Cardinal or a Telegram
bot. A logged-out session becomes “sign-in required”.

# 1.0.4

- Подписанный Edge-пакет теперь сам объявляет управляемый адаптер для Buywell Automation.
- После подключения блоки, поля входа и результаты становятся доступны без отдельной ручной регистрации адаптера.

# 1.0.3

- Драйвер теперь реализует все девять действий опубликованного адаптера NSGifts, включая баланс, курс и Steam Gifts.
- Идентификаторы контрактов приведены в точное соответствие с нодами Buywell Automation.

# 1.0.2

- Запросы NSGifts теперь всегда используют исходящий IPv4-адрес Edge — тот же адрес, который добавляется в whitelist провайдера.
- Запрещённый запрос теперь отличает отклонение IP от отсутствующего права API v2, когда NSGifts сообщает причину.

# 1.0.1

- Интерактивная настройка Edge получает русские и английские названия полей прямо из пакета NSGifts.

# 1.0.0

- Первый Edge-only драйвер NSGifts.
- Подпись HMAC-SHA256, двухчасовые сессии, TOTP и IP whitelist.
- Безопасное создание, оплата и сверка состояния заказа без слепых повторов.
